# Nuggets

Things worth keeping — quotes, half-thoughts, questions I couldn't answer, what a mentor
actually said. Append-only and deliberately unstructured. **Filing happens later.**

Capture in three seconds from anywhere:

```bash
vc note "Kelly: LPs re-up based on how you handled the bad news, not the good"
```

The Tuesday agent reads new entries and proposes where each belongs — a glossary term, a thesis
update, an assignment answer, a LinkedIn post — as a PR I approve or reject. Nothing files itself.

This is the file that makes this notebook mine rather than a summary of public articles.
