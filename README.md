## Source-link decoder

Assignment links are shaped `https://vcl.to/VI<sprint>-<session>` and redirect to public
articles on govclab.com. So `VI3-2` = Sprint 3, Session 2 = Venture Fund Economics.
Every source is public — no login needed.
